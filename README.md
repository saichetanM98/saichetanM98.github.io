# Saichetan Motte | Developer Portfolio

A minimal, highly responsive, and professional personal developer portfolio built to showcase my software engineering, AI, and cybersecurity projects. 

## 🚀 Overview

This repository contains the source code for my personal portfolio. It is designed to be fast, accessible, and easy to maintain without the overhead of heavy JavaScript frameworks. The design highlights my focus areas: Full-Stack Development, AI/GenAI, and Cybersecurity.

## 🛠️ Built With

* **Semantic HTML5**
* **Vanilla CSS3** (Custom properties, Flexbox, CSS Grid, animations)
* **Vanilla JavaScript** (Smooth scrolling, active navigation state)
* **Typography:** [Google Fonts](https://fonts.google.com/) (DM Mono, Manrope)

## 💻 Run Locally

Getting the portfolio running locally is instant:

1. Clone the repository or extract the ZIP file.
2. Double-click `index.html` to open it in any modern web browser.

*Note: There is no build step, `npm install`, or bundler required.*

## 📝 Pre-Launch Checklist

Before pushing this live, ensure you have completed the following:
- [x] **Contact Links:** Verify that the "Send an Email" and "Connect on LinkedIn" buttons point to your exact URLs.
- [x] **Project Media (Optional):** The current design uses stylized CSS elements for project visuals. If you prefer real screenshots, you can replace the `.visual-*` div containers with standard `<img src="..." alt="...">` tags.
- [x] **Resume Link:** If you want to offer a downloadable PDF of your resume, add a button in the Hero or About section linking to your `resume.pdf`.

## 🌐 Deployment

Because this is a static site, it can be hosted for free on almost any platform in seconds. 

**Publishing with GitHub Pages:**
1. Upload `index.html`, `style.css`, and this `README.md` to a public GitHub repository.
2. In your repository, navigate to **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch, leave the folder as `/ (root)`, and click **Save**.
5. GitHub will provide you with a live URL (e.g., `https://saichetanM98.github.io/portfolio`) within a few minutes.
